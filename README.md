# 🦖 Dino Retro

Um clone do jogo do dinossauro do Chrome (aquele que aparece quando você fica offline), feito em HTML, CSS e JavaScript puros — um único arquivo, sem dependências externas de build.

Totalmente responsivo: se adapta automaticamente ao tamanho da tela, funcionando tanto no computador quanto no celular (com suporte a toque).

## 🎮 Como jogar

- **Espaço** / **Seta para cima** / **Toque na tela** — Pular
- **Seta para baixo** — Abaixar

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub e envie este arquivo `index.html` para a raiz dele (branch `main`).
2. No repositório, vá em **Settings → Pages**.
3. Em **Source**, selecione a branch `main` e a pasta `/ (root)`.
4. Salve. Em alguns minutos o jogo estará disponível em:
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## 🖥️ Como testar localmente

Basta abrir o arquivo `index.html` diretamente no navegador — não precisa de servidor nem de instalação de nada.

## 🛠️ Estrutura

Este é um projeto **single-file**: todo o CSS, JavaScript e os sprites do jogo (em base64) estão embutidos dentro do próprio `index.html`. Isso facilita a hospedagem em qualquer lugar (GitHub Pages, Netlify, Vercel, ou até localmente).
